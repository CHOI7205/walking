# SPPB 상세페이지

`dist/index.html`을 브라우저로 열면 됩니다. 설치나 빌드가 필요 없는 반응형 HTML/CSS/JavaScript 페이지입니다.

SPPB 100을 중심으로 검사 소개, 채점 구조, 센서 구성, 결과 관리, 확장 검사, Portable, 근거, 사양 비교, FAQ, 도입 상담을 구성했습니다. 디자인은 기존 FITTO 상세페이지의 편집 흐름과 여백, 어두운 결과 섹션을 참고하고 네이비·민트 색상을 적용했습니다.

사진과 프로그램 화면은 사용자가 제공한 카탈로그에서 추출했습니다. 작은 원본 화면은 원래 해상도의 한계가 있습니다. 검사 사진은 카탈로그의 안내 장면입니다.

## 자료 기준
- SPPB 100 카탈로그 1~4쪽: 제품 구성, 센서 특징, 검사 항목, 프로그램, 치수, 문의처.
- SPPB 100 제품사양서 1쪽: 데이터 관리, 엑셀 출력, 국내 설치·운용교육, 보증 안내.
- Portable 카탈로그 1~2쪽: AI 비전, LiDAR, 24개 관절 추적, 4m 보행, 확장 지표.
- 신의료기술 고시 안내: 근감소증에서의 SPPB 신체기능 평가의 목적과 대상, 다른 측정지표와의 종합. 개별 제품 인증으로 표현하지 않음.
- Min & Min 제공 연구 원고: 41명, 수기 SPPB와 센서 기반 SPPB 총점 ICC 0.8654. Portable에 대한 성능 주장으로 적용하지 않음. 원고에 최종 DOI 정보가 없어 최종 출판 정보는 추가하지 않음.

## 최종 공급 전에 확인할 자료 차이
- 전용 의자: 카탈로그 430×500×750~840mm / 사양서 430×500×750~850mm.
- 균형 패드: 카탈로그 660×520×10mm / 사양서 6000×600(단위 누락). 상세페이지에는 카탈로그 치수만 사용.
- 거리 센서: 카탈로그 1~7m(최대 6m 측정) / 사양서 본문 0.3cm~7m, 사양 항목 0.3m~7m. 수치 혼용 없이 페이지에서는 구간 설정 지원으로 설명.
- 악력계: 카탈로그 구성품에 포함 / 별도 사양서 구성품 목록에는 없음. 최종 견적 구성 확인 안내.
- Portable: 카탈로그의 '8가지 평가' 표기와 열거된 항목 수가 일치하지 않아 개수를 홍보하지 않고 표준 검사와 확장 항목을 그대로 열거.
- 제품 허가/인증, 급여/수가, 가격, 효과 보장 등 제공 자료에서 확정할 수 없는 주장은 추가하지 않음.

## 사용·수정
- 내용: dist/index.html
- 디자인: dist/styles.css
- 화면 확대: dist/app.js
- 사진: dist/assets/

전화·이메일 버튼은 카탈로그의 피지오컴퍼니 문의처로 연결합니다. 문의 접수 서버는 없습니다. 실제 전화·이메일 발송은 하지 않았습니다.

검증: PC 1440px, 모바일 390px에서 가로 넘침과 이미지 누락 없음. 결과 화면 확대·Escape 닫기·FAQ 열기 동작 확인. JavaScript 구문 검사와 브라우저 오류 확인 완료.
