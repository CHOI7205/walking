# 블로그 콘텐츠 제작 기준

- 사용자 전공·학위: 물리치료 전공, 스포츠의학 석사, 재활의학 박사.
- 전문 독자에게도 도움이 되도록 원저 논문, 체계적 문헌고찰, 전문학회·공공기관 자료를 충분히 검토한다. 근거 수준, 연구 대상과 한계를 구분하고 출처를 제시한다.
- 대표 이미지는 사용 권한을 확인한 실제 사진·연구 이미지 등을 우선 사용한다. AI 생성 이미지는 사용하지 않는다. 저자·출처·라이선스 및 편집 여부를 표시한다.
- 전문 용어는 정확히 쓰되 일반 독자도 이해할 수 있게 설명한다. 전문성과 읽기 편한 구성을 함께 갖춘다.
- 2026년 11월 24일 블로그는 슬로우 조깅 글로 확정했다. 이날 추가 글은 제작하지 않는다.

## 검색에서 협회 활동을 명확히 전달하기 (2026-11-25 사용자 요청)

- 활동 사례를 우선하고 보도자료·협회 이야기에도 적용한다. 목표는 정확한 협회명 검색에서 우리 협회의 기록이 함께 발견되도록 돕는 것이다. 검색 순위와 홈페이지 아래 배치를 보장하지 않는다.
- 활동 제목은 기관명과 구체적인 교육 주제를 간결하게 쓴다. 예: `양천구보건소 바른자세 걷기 교육`. HTML 제목에는 사이트가 붙이는 `대한바른자세걷기협회` 표기가 정확히 한 번만 나오도록 확인한다. 기관명이나 협회명을 불필요하게 반복하지 않는다.
- 활동 글의 첫 문단에 확인된 진행 주체인 `대한바른자세걷기협회`, 기관·장소, 시기, 대상과 실제 교육 내용을 자연스럽게 설명한다. 확인되지 않은 역할·인원·날짜·성과·후기는 만들지 않는다. 일반 걷기 정보 글을 협회가 실제 진행한 행사처럼 쓰지 않는다.
- 본문은 해당 현장의 구체적인 활동과 독자에게 도움이 되는 내용으로 작성한다. 소제목은 측정·교육·실습 내용을 드러내고, 사진에는 실제 장면에 맞는 설명과 대체문구를 붙인다. 참고 사진은 구분한다. 동일 원고의 대량 재게시와 검색어 나열을 피한다.
- 관련 활동 사례, 교육 프로그램, 보도자료 원문을 내용에 맞게 연결한다. 발행 주체는 실제 협회·작성자 정보와 일치시킨다. 공식 홈페이지 글을 별도 네이버 블로그나 다른 협회의 글로 표시하지 않는다.
- 게시 시 제목·요약·본문·사진·작성자·출처의 일치, HTTP 200, 검색 허용, 자기 주소 canonical, Article 발행 주체, 사이트맵 포함과 목록의 실제 링크를 확인한다. 보도자료 RSS에는 공개 글의 전체 본문·사진·원문 링크가 전달되는지 확인한다. 실제 발행·수정일만 사용한다.
- 게시 후 수집·색인과 실제 검색 노출을 구분해 확인한다. 필요 시 미수집 주요 글만 선별해 수집 요청하며 같은 URL을 매일 재제출하지 않는다. 다른 협회의 글 삭제나 순위 하락을 요청하지 않는다.

## 기존 글 전체 SEO 정비 및 향후 작성 기준 (2026-11-27)

- 협회명뿐 아니라 글별 검색 의도에 맞는 걷기 방법, 바른 자세 걷기, 족압 분석, 신발 선택, 근력·균형운동 등의 주제를 제목·요약·소제목에 자연스럽게 반영한다. 모든 글에 같은 검색어를 나열하지 않는다.
- 게시된 URL과 발행일은 유지한다. 제목·검색 설명과 본문·출처·사진 설명을 일치시키고, 실제 수정일을 기록한다.
- 제목은 협회명이 중복되지 않게 구성한다. H1은 하나만 두고 H2·H3와 목차를 사용하며, 관련 정보와 교육 프로그램을 실제 링크로 연결한다.
- 최신 자료를 확인하되 검토하지 않은 연구를 최신 근거로 표시하지 않는다. 글의 전문성·연구 한계·출처는 유지한다.
- 향후 새 글의 게시 전에는 사용자에게 완성본을 확인받는다. 사용자가 해당 수정·게시를 명시적으로 승인한 경우에는 다시 승인을 요구하지 않는다.
